# Computer Graphics

This course isn't really from the "Laurea Triennale in Informatica" program, it is from the "Laurea Triennale in Informatica per la Comunicazione Digitale" program, but I took it because it was interesting and I wanted to learn more about computer graphics.

The course is taught by Prof. Tarini, and the official page of the course can be found [on his website](https://tarini.di.unimi.it/teaching/cg2026/), he subdivides the course into two parts: the first part is about 3D model representation and the second part is about rendering.

The notes are in Markdown format.
